# Machine Learning in R for Clinical Research · Machine learning en R para investigación clínica

**[English](#english) · [Español](#español)**

---

## English

A beginner-friendly, step-by-step course on machine learning in R for
clinical research. It uses real public data, and every line of code is
explained in R Markdown. It covers logistic regression, LASSO, random forest,
XGBoost and LightGBM, plus calibration, decision curves, TRIPOD+AI reporting
and a reusable study template. No coding experience needed.

➡️ **[Start the course in English](en/README.md)**: open
`en/ML_in_R_course.Rproj` in RStudio.

## Español

Un curso paso a paso de machine learning en R para investigación clínica,
pensado para principiantes. Usa datos públicos reales y explica cada línea de
código en R Markdown. Incluye regresión logística, LASSO, random forest,
XGBoost y LightGBM, además de calibración, curvas de decisión, reporte con
TRIPOD+AI y una plantilla reutilizable para estudios. No hace falta
experiencia en programación.

➡️ **[Empieza el curso en español](es/README.md)**: abre
`es/curso_ML_en_R.Rproj` en RStudio.

## Repository structure · Estructura del repositorio

```text
├── en/   English course (8 lessons + README)
├── es/   Curso en español (8 lecciones + README)
├── LICENSE
└── README.md
```

Both versions contain identical R code. Only the explanations, comments and
plot labels are translated. Variable and function names stay in English in
both.

Las dos versiones tienen el mismo código R. Solo se traducen las
explicaciones, los comentarios y las etiquetas de los gráficos. Los nombres
de variables y funciones se mantienen en inglés en ambas.
